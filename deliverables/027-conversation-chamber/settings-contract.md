# Soul Sea Reader Appraisal contract

## Product frame

Settings is the reader-profile space inside the Soul Sea. It uses the existing
Hidden Thread materials: black mantle depth, silver thread structure, old-gold
selected state, and restrained crimson for destructive or failed actions.

The interface keeps plain settings labels. Lore controls its structure and
motion without obscuring what a control does.

## Information structure

1. Reader position joins chapter reach and spoiler protection.
2. Answer depth owns Awakened, Ascended, and Transcendent reading tiers.
3. Bound voice owns the browser-local DeepSeek key and model choice.
4. Appearance owns the selected Soul Sea, rune motion, star-web intensity,
   density, and text size.
5. Privacy and controls states the real browser, local-library, and DeepSeek
   boundaries alongside keyboard shortcuts.
6. First Nightmare owns the replay action.

Shadow Slave keeps one fixed Hidden Thread Edition identity. Reader-facing
message-glass controls leave the settings UI. The owner accepted three Soul Sea
identities on 2026-08-22: Sunny's mature dark sea, an ordinary bright Soul Sea,
and Nephis' radiant sea. Selection changes the distant realm beneath the
existing star web and never replaces the Spellweave.

## Phone behavior

- Settings fills the safe viewport.
- The first view is a vertical settings index with current-value summaries.
- Choosing a row opens one detail view with a clear Settings back action.
- There is no horizontal settings tab strip.
- Controls are at least 44px and form text is at least 16px.

## Desktop behavior

- A left navigation thread and right detail surface share one dialog.
- The active section uses an old-gold knot on the thread rather than a rounded
  selected card.
- The Soul Sea horizon is ambient structure and does not displace the form.

## Reader position

- Chapter is the editable source of truth, clamped to the accepted 1 through
  3160 backend range.
- Volume is derived from chapter and cannot contradict it.
- Buttons adjust the chapter by minus 10, minus 1, plus 1, and plus 10.
- Spoiler protection lives on the same page and names the current boundary.

## Save and privacy

- Changes remain draft state until Apply changes.
- Closing dirty settings asks before discarding.
- Saving keeps the current API contract and browser-local visual preferences.
- API key text never enters labels, summaries, logs, or snapshots.
- Privacy copy states that threads and preferences use Weaver's local library,
  messages go to DeepSeek for replies, and the key stays in browser storage.
