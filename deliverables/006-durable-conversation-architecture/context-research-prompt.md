# Plan 006 context research brief

## Question

What can Weaver take from Pi, Codex, Claude Code, Hermes, Honcho, LangGraph,
and Karpathy's LLM Wiki pattern without confusing exact conversation evidence,
relationship memory, literary understanding, and workflow state?

## Fixed constraints

- The private library is immutable except through the admitted Plan 002 tools.
- Exact conversation items are canonical and never replaced by a summary.
- Raw model reasoning stays ephemeral.
- The owner and Weaver remain separately attributed.
- Literary claims are later experiments, not Plan 006 memory records.
- A workflow framework may coordinate work but may not own Weaver's evidence.
- Public prompt labels can guide a model, but they cannot enforce a storage
  boundary or prove that canon and opinion stayed separate.

## Questions used for each source

1. What identity does the system give a conversation and one user request?
2. Which records survive restart?
3. What is canonical, and what is only a model-context view?
4. Can retry or resume repeat model calls or side effects?
5. How are active steering and queued follow-up kept distinct?
6. How does cross-conversation memory keep author and source identity?
7. Which ideas fit Weaver now, later, or not at all?

## Evidence standard

Pinned source revisions support code claims. Moving product documentation is
labelled as moving documentation and checked on 2026-07-30. Research-agent
transcripts and machine acceptance blobs are not evidence.

## Required conclusion shape

- observations;
- rejected designs;
- accepted Plan 006 decisions;
- later hypotheses for Plan 009;
- open questions that still require an experiment.
