# Plans in discussion

Pre-draft ideas. Nothing here runs.

- One file per idea: `NNN-slug.md`, with a provisional number.
- Created by `uv run python scripts/scaffold_plan.py NNN slug --discussion`.
- At most 5 open.
- No slices, no budget, no deliverables, no commits from here.
- Allowed to be wrong, rewritten, or deleted.
- Promoted by drafting the real plan
  (`uv run python scripts/scaffold_plan.py NNN slug`), then deleting this doc
  in the same commit. Git keeps the history.
- Only 3 plans may be drafted at once, so the rest of the thinking waits
  here.
- Recorded in `plans/README.md` as `Idea (provisional)`.

This folder replaces `handoff/plans/`, which was the same idea without a home
(retired 2026-11-18).
