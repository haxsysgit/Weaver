## Scope

- Baseline on Linux: full backend suite, frontend tests, `tsc`, build, a
  live turn.
- `weaver schedule install|remove|status` on Linux through a systemd user
  timer; `notify-send` alerts for the scheduled run.
- Persistent embedding-model cache off Windows (`/tmp` is cleared at boot).
- `.claude/launch.json` without PowerShell (local file, not committed).
- `AGENTS.md` and `HANDOFF.md` notes that assumed Windows.
- An audit of encodings, line endings, file-name case, stored path
  separators, file modes and shell-outs.

## Out of scope

- Enabling the timer, enabling linger, changing file modes, normalising
  line endings: owner decisions, listed in `results.md`.
- A launcher for the DSH `web` profile (the old `weaver.cmd`).
- Plan 036 and anything in the Reader Trials.

- A fix would need to remove or rewrite a Windows code path.
- A fix would touch `novels/`, the search index, or the owner's
  uncommitted files beyond the lines the owner named.
- Any step would enable the timer or spend beyond one live turn.
