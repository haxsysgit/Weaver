## Scope

- **The publication pass keeps the thread's own answers.** The final reread
  that publishes a turn is built from the current reader message alone
  (`final_history` in `agent/turn.py`), so it cannot see a list it gave two
  turns ago. Give it the last few reader/Weaver exchanges of this thread,
  bounded, and only the messages the reader actually saw.
- **A fight the reader named is followed to its end.** End-of-scene
  follow-ups ("who actually won?", "how did it end?") carry the earlier
  scene skill instead of dropping to a four-lookup quick recall; the scene
  read is sized so a ten-chapter fight fits (lookups 8 to 16, packet
  16,000 to 24,000 characters, matching `arc_summary`).
- **No machinery talk in a published answer.** Extend the existing
  exposed-machinery check with the phrases the 033.6 transcripts show
  ("this turn only gave me", "lookups"), with negative tests so normal
  speech does not fire it.
- Deterministic tests for each, written red first.

## Out of scope

- The Plan 033 check set (retrieval arm A). Plan 034 owns it.

   close, plus this plan's new tests.

3. `npx vitest run` (185 tests), `npx tsc --noEmit`, `npm run build` pass.
4. A fresh reviewer agent with no part in the build reads the diff and its
   findings are repaired or recorded in `review-ledger.md`.
5. The live run (slice 8) records build hash, per-trial spend, both axis
   verdicts, and the quotes it checked.

## STOP conditions

- A new test needs a fixture that would import the real `.env` or a live
  model.
- A fix would have to key on the trial wording, the specific fight, or a
  specific character.
- The live run's metered spend would pass the $1.50 cap.
- Two consecutive trial failures have the same cause after a fix.
- The full floor fails twice on the same cause.
